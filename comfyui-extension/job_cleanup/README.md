# job_cleanup (a ComfyUI extension for Comfy)

ComfyUI has no delete API, and Comfy may run on another machine, so once Comfy has stored a job's
results it cannot remove the copies ComfyUI wrote. This extension adds one route,
`POST /job-cleanup`, that deletes exactly the files Comfy names. Without it, `output`, `temp` and
`input/comfy` grow forever. It is optional: leave it out and Comfy still works, it just leaves the
files in place.

What it will and will not do:

- Needs a shared secret: `JOB_CLEANUP_TOKEN` on the ComfyUI process. Unset or shorter than 16
  characters, the route answers `503 cleanup disabled`. A wrong or missing `Authorization: Bearer`
  header gets `401` (constant-time comparison).
- Deletes regular files only, in ComfyUI's `output` and `temp` folders, plus `input/comfy` for
  Comfy's own `comfy-<uuid>.<ext>` reference uploads. Never directories, never other input paths.
- Refuses traversal, absolute paths, drive letters, backslashes, NUL, symlinks and junctions that
  leave the folder, odd file names, and more than 64 files per request.
- Idempotent: a file that is already gone counts as `missing`. The answer is only counts,
  `{"deleted":n,"missing":n,"refused":n}`; no paths are echoed or logged.

**The route is as exposed as ComfyUI itself**: anyone who can reach ComfyUI's port can call it, and
the token is the only protection. Keep that port reachable only from the machine running Comfy, and
use a long random token.

## Install (on the machine that runs ComfyUI)

1. Copy this whole `job_cleanup` folder into `ComfyUI/custom_nodes/` (so
   `custom_nodes/job_cleanup/__init__.py` exists).
2. Make a token, for example `openssl rand -hex 24`, or in PowerShell
   `-join ((48..57)+(65..90)+(97..122) | Get-Random -Count 40 | % {[char]$_})`.
3. Set `JOB_CLEANUP_TOKEN=<token>` in the environment of the ComfyUI process, then restart ComfyUI.
4. Set the same value as `COMFYUI_CLEANUP_TOKEN` in Comfy's environment and restart Comfy. Leave
   it unset to keep cleanup off.

The ComfyUI log should show the custom node importing without errors.

## Test with curl

```
# 503 means the env var is not set on the ComfyUI process; 401 means the token is wrong
curl -i -X POST http://COMFYUI_HOST:8188/job-cleanup \
  -H "Authorization: Bearer TOKEN" -H "Content-Type: application/json" \
  -d '{"files":[{"filename":"does-not-exist.png","subfolder":"","type":"output"}]}'
```

Expect `{"deleted": 0, "missing": 1, "refused": 0}`. Try `"type":"models"` or
`"filename":"../x.png"`: they must come back as `refused`. To test a real delete, drop a throwaway
`zz-test.png` in `output` and name it.

Self-test of the path logic (no ComfyUI needed): `python selftest.py` in this folder.

## Safety net: scheduled sweep

If the extension is missing, ComfyUI was down, or a job crashed, old files remain. The sibling
script `../cleanup-old-files.ps1` (Windows PowerShell) deletes files older than N days (default 2)
in `output`, `temp` and `input\comfy`. **It also removes anything you generated by hand in
ComfyUI's own UI that is still in `output`.** Try it first with `-WhatIf`:

```
powershell -File C:\path\cleanup-old-files.ps1 -ComfyRoot C:\path\to\ComfyUI -WhatIf
schtasks /Create /TN "ComfyJobCleanup" /SC DAILY /ST 04:00 /TR "powershell -NoProfile -ExecutionPolicy Bypass -File C:\path\cleanup-old-files.ps1 -ComfyRoot C:\path\to\ComfyUI -Days 2"
```
